# Pointage Serre

Système de pointage pour la gestion de serre — Application mobile-first.

## Déploiement

Ce site est hébergé sur Netlify. Toute modification pushée vers ce dépôt est automatiquement déployée.

## Base de données

Les données sont stockées dans **Supabase** (PostgreSQL).
- URL: `https://zyahmqbdqjdklthdwiiw.supabase.co`
- Tables: `settings`, `submissions`, `wip`
